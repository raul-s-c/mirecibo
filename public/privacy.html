MiRecibo

Política de privacidad

Última actualización: 2 de septiembre de 2026

Resumen

MiRecibo está diseñada para guardar tu lista, tickets, repostajes y estadísticas en tu dispositivo. No vende datos, no incorpora publicidad y no necesita una cuenta para funcionar.

Datos tratados

  • Datos que introduces: productos, tickets, importes, establecimientos, vehículos y código postal.
  • Fotografías de tickets y texto reconocido cuando solicitas expresamente su análisis.
  • Un identificador aleatorio de instalación y datos técnicos mínimos necesarios para seguridad, límites de uso y diagnóstico.

Finalidad y almacenamiento

Los datos funcionales se conservan localmente hasta que los borres o desinstales la aplicación. Puedes exportar una copia y eliminar todo desde Ajustes. Al analizar un ticket, la imagen y el texto reconocido se transmiten cifrados al servicio de MiRecibo y a OpenAI únicamente para devolver una interpretación estructurada. La aplicación solicita que la respuesta no se almacene como estado de conversación.

Precios y zona

El código postal se usa para buscar y comparar referencias cercanas. No se solicita una dirección exacta ni ubicación GPS.

Terceros y seguridad

El procesamiento inteligente usa la API de OpenAI mediante un servicio protegido en Cloudflare. Estos proveedores pueden tratar datos técnicos y conservar registros de seguridad de acuerdo con sus condiciones aplicables. La clave del servicio nunca se distribuye dentro de la aplicación.

Tus decisiones

Puedes usar las funciones locales sin escanear tickets, corregir cualquier resultado antes de guardarlo, exportar tus datos o borrarlos por completo. Antes de una publicación pública se indicará aquí el correo definitivo de soporte y privacidad del responsable.
